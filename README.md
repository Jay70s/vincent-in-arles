# Vincent in Arles — 아를의 반 고흐

빈센트 반 고흐가 아를에 머문 15개월(1888년 2월 ~ 1889년 5월)의 편지 **173편**을
정리한 웹사이트 + 검색 가능한 위키입니다.

- **스토리 사이트** — 15개월의 내러티브, 그가 편지에 적은 색채 묘사를 실제 색칩으로,
  아를 지도, 편지 속 인물들
- **위키** (`/wiki/`) — 편지 173편 · 인물 316명 · 주제 19개 · 특집 2편,
  총 513개 문서가 서로 링크되어 있고 한국어·영어 전문 검색 지원
- **지식 그래프** (`/explore/graph.html`) — 508개 노드, 2,085개 연결의 인터랙티브 그래프
- **데이터 대시보드** (`/explore/charts.html`) — 월별 편지, 주제 흐름, 인물 랭킹 등 7종
